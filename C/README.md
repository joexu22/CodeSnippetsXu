# C language — authority & references

C is defined by an international standard, not by a single vendor site.

| | |
|--|--|
| **Committee** | ISO/IEC JTC 1/SC 22/WG 14 (**WG14**) |
| **Standard** | ISO/IEC 9899 (*Programming languages — C*) |
| **Current edition (as of 2024)** | ISO/IEC 9899:2024 (**C23**) |

## Where to look

- **Committee / free drafts & working documents**  
  https://www.open-std.org/jtc1/sc22/wg14/

- **Official published standard (purchase)**  
  https://www.iso.org/standard/82075.html  
  (ISO/IEC 9899:2024; product page for this edition — search ISO for later editions if this link ages)

- **Near-final free draft for C23**  
  https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf

- **Community index of revisions & links**  
  https://www.c-language.org/

- **Practical language & library reference**  
  https://en.cppreference.com/w/c

- **Common compilers**  
  https://clang.llvm.org/ · https://gcc.gnu.org/
